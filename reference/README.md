# Reference solutions

One folder per finished lab, published after the session. Each is **one theme's** answer.

- **Same theme as yours?** You may copy it to catch up. Say so when you're verified.
- **Different theme?** Read it for the *shape* (which types, which responsibilities, where validation lives), then write your own.

This folder is not compiled into your project, and `sq update` replaces it, so don't edit it.
Copying is allowed, but it doesn't earn the grade: 60% of every lab is a live change and two "why" questions about **your** code.
